overlapmark

Highlights that overlap get darker, and a click names every highlight under it. For vanilla JS, Vue, React and Svelte.

npm install @overlapmark/dom @overlapmark/core
README on GitHub @overlapmark/dom @overlapmark/vue @overlapmark/react @overlapmark/svelte

Analyses of a passage

Overlap

Strategy

    Hover to preview, click to inspect. Select any words to add your own analysis (long-press, then drag the handles). Keyboard: Tab to a highlight, Enter to inspect.

    Make it yours

    The look is plain CSS. Set the theme variables, pick a preset class or your own, and decorate segments with markup such as a count.
